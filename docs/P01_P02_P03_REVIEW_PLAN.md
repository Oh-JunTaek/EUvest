# P0-01~03 재점검 계획 — 2026-11-04

상위 티켓을 한 번에 하나씩 점검한다. 기존 변경 및 미추적 파일과 로컬 DB는 보존한다.

1. P0-01: `API_VERIFICATION_LOG.md`와 공식 소스를 대조하고 확인 가능한 근거와 미확인 사항을 분리한다. 주문·인증 호출은 하지 않는다. 환경 및 패키지 실행 가능성을 확인한다.
2. P0-02: `pyproject.toml`, 잠금 파일, 설정 모델과 테스트를 점검한다. 기본 모드, 강제 위험 제한, 모드 분리, 비밀 마스킹, 설정 오류를 검증한다. 실제 인증은 미확인이다.
3. P0-03: 스키마·모델·저장소와 문서 03을 비교하고 보존 가능한 변경만 구현한다. 백업/롤백/동시성/버전/금액과 시간 및 인수 항목을 테스트한다. 기존 데이터 이행 규칙이 명세에서 확정되지 않으면 `11_OPEN_DECISIONS.md`에 기록하고 임의 변환하지 않는다.

각 단계의 목표는 해당 티켓의 테스트, 전체 회귀와 Ruff의 실제 결과를 남기는 것이다. 미래 티켓의 실행기와 실제 브로커 동작을 현재 구현된 것으로 표시하지 않는다.
