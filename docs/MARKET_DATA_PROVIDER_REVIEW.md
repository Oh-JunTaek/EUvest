# 무료 시장 데이터 공급자 조사 및 선정 보고서

**작성일**: 2026-11-14
**작성자**: Cline
**검토 상태**: 초안 (사용자 승인 대기)

---

## 1. 요약

EUvest에서 국내(KRX)·미국(NASDAQ/NYSE) 주식 및 ETF의 실제 가격 데이터(OHLCV, 현재가, 거래량)를 수집하기 위한 무료 데이터 공급자를 조사·비교하였다.

| 순위 | 공급자 | 추천도 | 비고 |
|------|--------|--------|------|
| 1순위 | **FinanceDataReader (fdr)** | ⭐⭐⭐ 추천 | 국내 주식/ETF 네이티브 지원, KRX 직접 소스, MIT 라이선스 |
| 2순위 | **KIS Open API** | ⭐⭐ 예비 | 공식 브로커 API, 실시간 WebSocket, 계좌 필요 |
| 3순위 | **yfinance** | ⭐ 비추천 | KRX 데이터 품질 낮음, 비공식, 비율 제한 불명확 |

> **결론**: **FinanceDataReader(fdr)**를 1순위 공급자로 선정하고, 실시간 데이터가 필요할 때 KIS Open API를 보조로 사용한다.

## 2. 공급자별 상세 비교

### 2.1 FinanceDataReader (fdr) — **1순위 추천**

| 항목 | 내용 |
|------|------|
| **패키지명** | `finance-datareader` (PyPI), `uv add finance-datareader` |
| **라이선스** | MIT |
| **지원 시장** | KRX(KOSPI/KOSDAQ/KONEX), NASDAQ, NYSE, AMEX, S&P500, SSE, SZSE, HKEX, TSE, HOSE 등 |
| **KRX 지원** | ✅ 네이티브 지원 (종목코드 `005930` 또는 `KRX:005930`) |
| **미국 주식 지원** | ✅ `AAPL`, `SPY` 등 심볼 직접 사용 |
| **ETF 지원** | ✅ `ETF/KR` 리스팅, 개별 ETF 가격 조회 |
| **데이터 소스** | - **KRX**: 네이버 금융(2000~), KRX 직접(1995~) 2년 단위 병합
- **미국**: 야후 파이낸스 폴백
- **지수/환율/FRED**: 다수 지원 |
| **데이터 타입** | 현재가(종가), OHLCV, 거래량, 상장종목 리스팅, 지수, ETF 리스팅, 환율, 재무제표 |
| **API 키** | 불필요 (웹 크롤링 기반) |
| **비율 제한** | 소스 사이트(네이버/KRX) 의존, 공식 문서 없음. 과도 호출 시 IP 차단 가능성 |
| **실시간성** | 장마감 후 일봉 데이터 (EOD), 실시간 아님 |
| **한국 주식 품질** | ⭐⭐⭐ 우수 - KRX 직접 소스(1995~), 상세 필드 제공 |
| **미국 주식 품질** | ⭐⭐ 보통 - 야후 파이낸스 폴백, 조정주가 기본 |
| **라이선스** | MIT (상업적 이용 가능) |
| **CLI 지원** | `fdr price AAPL --start 2024` 등 터미널 직접 조회 가능 |
| **출력 형식** | pandas DataFrame, CSV/JSON/Markdown 출력 지원 |

**장점**
- 한국 시장에 최적화된 네이티브 KRX 지원
- API 키 없이 즉시 사용 가능
- MIT 라이선스로 상업적 이용 자유
- ETF/KR 리스팅 등 한국 시장 메타데이터 풍부
- 재무제표, 지수, 환율, FRED 데이터까지 원스톱

**단점/주의사항**
- 실시간 데이터 불가 (장마감 후 데이터)
- 과도한 요청 시 소스 사이트(네이버/KRX)에서 IP 차단 가능
- 비율 제한 공식 문서 없음 (적정 호출 간격 유지 필요: 1~2초 권장)
- 미국 주식은 야후 파이낸스 폴백이라 조정주가 기본 (`auto_adjust=True` 기본값)

**EUvest 재사용 가능 부분**
- `market/market_data.py`의 `OHLCV`, `Quote` 데이터 클래스와 직접 매핑 가능
- `normalize_asset_id` / `parse_asset_id` 유틸리티와 호환되는 심볼 형식(`005930` → `KRX:005930`)
- `MARKET_LOT_SIZES` 등 시장 메타데이터와 연계 가능

### 2.2 KIS Open API (한국투자증권) — **2순위 예비**

| 항목 | 내용 |
|------|------|
| **공식 명칭** | 한국투자증권 Open API (KIS Developers) |
| **제공 방식** | REST API + WebSocket |
| **인증** | OAuth2 (AppKey + AppSecret → Access Token, 24시간 유효) |
| **지원 시장** | 국내주식(KRX), 해외주식(미국/중국/홍콩/일본/베트남) |
| **KRX 지원** | ✅ 공식 지원 (전 종목) |
| **미국 주식 지원** | ✅ 나스닥/뉴욕/아멕스 지원 |
| **ETF 지원** | ✅ 국내/해외 ETF 모두 지원 |
| **데이터 타입** | 현재가, 호가(매수/매도), 체결가, 일봉/주봉/월봉, 거래량, 호가잔량 |
| **실시간성** | WebSocket 실시간 시세 수신 가능 |
| **API 키** | 필수 (한국투자증권 계좌 개설 + API 신청 승인 필요) |
| **비율 제한** | 공식 문서에 초당/분당 제한 명시 없음. 과도 호출 시 차단 가능성. |
| **계좌 필요** | 실계좌 또는 모의계좌 (모의투자 지원) |
| **라이선스/약관** | KIS Developers 이용약관 준수, 상업적 이용 시 제휴 필요 |
| **공식 샘플** | GitHub 파이썬 샘플코드 제공 (REST/WebSocket) |
| **한국 주식 품질** | ⭐⭐⭐ 최고 - 공식 거래소 데이터, 실시간 호가/체결 |
| **미국 주식 품질** | ⭐⭐⭐ 양호 - 제휴 거래소 데이터 |
| **환율** | USD/KRW 실시간 환율 제공 |

**장점**
- 공식 브로커 API로 데이터 신뢰도 최고
- 실시간 WebSocket 시세 수신 가능
- 호가(매수/매도 잔량), 체결 실시간 수신
- 모의투자(Paper) 환경 제공으로 개발/테스트 용이
- 공식 기술지원 및 문서화

**단점/주의사항**
- **한국투자증권 계좌 필수** (개설 및 API 승인 과정 필요)
- API 키 발급·관리 필요 (Access Token 24시간 갱신)
- 상업적 이용 시 제휴 계약 필요 (이용약관 확인 필수)
- 비율 제한 문서화 부족 (과도 호출 시 차단 위험)
- 해외주식 실시간은 WebSocket만 지원 (REST는 지연 데이터)

**EUvest 재사용 가능 부분**
- `broker/kis_adapter.py` 읽기 전용 어댑터로 래핑 가능
- `BrokerProtocol.get_quote()` 인터페이스와 매핑 가능
- OAuth 토큰 관리 로직 별도 모듈로 분리 가능

### 2.3 yfinance — **비추천 (3순위)**

| 항목 | 내용 |
|------|------|
| **패키지명** | `yfinance` |
| **라이선스** | Apache 2.0 |
| **KRX 지원** | 제한적 (Yahoo Finance 경유: `005930.KS` KOSPI, `005930.KQ` KOSDAQ) |
| **데이터 품질** | ⭐ 낮음 - KRX 데이터 불완전, 지연 심함, 종목 누락 다수 |

| **API 키** | 불필요 |
| **비율 제한** | 비공식, 야후 스로틀링 적용 (~2,000 req/hr 추정) |
| **실시간성** | 15분 이상 지연 |
| **한국 ETF** | 지원 불완전 (종목코드 매핑 불일치 다수) |
| **라이선스** | Apache 2.0 |

**비추천 사유**
- KRX 데이터가 Yahoo Finance를 경유하여 **지연·불완전·종목 누락** 심각
- 한국 ETF 티커 매핑 불일치로 조회 실패 빈번
- 비공식 API로 언제든 중단/변경 가능
- 비율 제한 불명확, 과도 사용 시 영구 차단 위험
- 실무용으로는 데이터 품질 미달

## 4. 추천 근거 및 선정 이유

### 1순위: FinanceDataReader (fdr)

**선정 이유**
1. **한국 시장 최적화**: KRX 직접 소스(1995~)로 데이터 완전성·정확도 최고
2. **즉시 사용 가능**: API 키·계좌 없이 `uv add finance-datareader`로 즉시 개발 착수
3. **MIT 라이선스**: 상업적 이용·수정·재배포 완전 자유
4. **메타데이터 풍부**: `ETF/KR` 리스팅, 상장폐지/관리종목, 지수구성종목 등 한국 시장 전용 메타데이터 제공
4. **EUvest 아키텍처 부합**: 기존 `market/market_data.py` 데이터 클래스(`OHLCV`, `Quote`)와 직접 매핑, `normalize_asset_id` 호환
5. **확장성**: 재무제표, 지수, 환율, FRED 데이터까지 단일 패키지로 커버

**수용 가능한 제약**
- 실시간 데이터 불가 → EUvest는 `OFFLINE_SIM`/`KIS_PAPER` 모드에서 일봉 기준 의사결정이므로 수용 가능
- 비율 제한 비공식 → 요청 간격 1~2초 유지, 캐싱 레이어 추가로 완화 가능

---

### 2순위(예비): KIS Open API

**활용 시나리오**
- 실시간 호가/체결 필요 시 (WebSocket)
- 실계좌 연동 후 실시간 모니터링
- 모의투자(Paper) 환경에서 주문 전 시세 검증

**선정 보류 사유**
1. **계좌 개설·승인 선행 필요** → 개발 착수 지연
2. **상업적 이용 시 제휴 필요** → 법무 검토 선행 필요
3. **비율 제한 불명확** → 운영 안정성 검증 필요
4. **개발 환경 복잡도** → 토큰 관리, WebSocket 연결 관리 등 추가 복잡도
